# 机器学习基础概念

## 过拟合与欠拟合

过拟合（overfitting）指模型在训练集上表现很好，但在未见过的测试数据上
表现明显下降——模型把训练样本中的噪声也当成规律记住了。欠拟合（underfitting）
则相反：模型太简单，连训练集里的基本规律都没学会，训练误差和测试误差都高。

判断方法：画出训练误差与验证误差随训练进程的曲线。训练误差持续下降而
验证误差开始上升，是过拟合的典型信号；两条曲线都停在高位，是欠拟合。

## 缓解过拟合的常用手段

1. **正则化**：在损失函数中加入参数复杂度惩罚项。L1 正则（权重绝对值之和）
   倾向产生稀疏权重，可做特征选择；L2 正则（权重平方和）让权重整体变小、
   模型更平滑，是最常用的默认选择。
2. **Dropout**：训练时随机丢弃一部分神经元的前向激活，迫使网络不依赖
   特定神经元组合，等效于隐式集成大量子网络。
3. **早停（early stopping）**：监控验证集指标，验证误差不再改善时停止训练，
   保留验证误差最低时的参数快照。
4. **数据增强**：对训练样本做保持语义的变换（图像翻转裁剪、文本同义替换），
   等效于扩大训练集、降低模型对特定样本的记忆。
5. **交叉验证选超参数**：k 折交叉验证把训练数据分成 k 份轮流做验证，
   超参数的评估更稳定，降低"在单一验证集上过拟合"的风险。

## 偏差与方差

偏差（bias）描述模型预测值与真实值的系统性偏离，来自模型假设过强；
方差（variance）描述模型对训练集扰动的敏感程度，来自模型过于灵活。
欠拟合对应高偏差，过拟合对应高方差。容量更大的模型偏差更低、方差更高，
正则化的本质是在两者之间做权衡。

## 泛化与数据划分

规范的数据划分是训练集 / 验证集 / 测试集三段：测试集只能在最终评估时
使用一次，反复用测试集调参会让它退化成另一个验证集，泛化指标失真。
数据量小的时候优先用交叉验证而不是单次划分，以降低评估的随机性。
